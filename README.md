# Project Definition Workshop

A guided Manus workflow for turning an early-stage idea into a clear, actionable project definition. It explores relevant dimensions adaptively, asks one question at a time, and produces a compact brief.

The workflow helps classify the next step as **build**, **validate**, **decide**, or **park**. It is a Manus workflow skill, not an application. It does not automatically conduct research, build a product, or deploy anything.

Import into Manus from GitHub: https://github.com/Smartball17/project-definition-workshop

No external dependencies or paid APIs are required. Running the workflow in Manus consumes Manus credits; any credit savings have not been measured.
